# Dream House — Casa de Pátio

Planta baixa interativa da casa dos sonhos: uma casa de pátio (atrium house) de 220 m² pensada para o clima do Nordeste.

Abra `planta_baixa_interativa_casa_de_p_tio.html` no navegador. Não há build — é uma página única que usa Tailwind e Font Awesome via CDN.

## Modos

- **Planta Baixa** — clique nos ambientes para ver área, pé-direito, piso, ventilação e benefícios bioclimáticos.
- **Tour Guiado** — percorra os ambientes um a um.
- **Orçamento** — estimativa de custos por etapa da obra.
